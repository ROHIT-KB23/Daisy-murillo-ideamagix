📋 About This Project
This is a portfolio website for Daisy Murillo - a computer science student and Infrastructure engineer. The website showcases skills, projects, and contact information with a clean design.

✨ Features

Page Loader - Spinner animation when page loads
Fully Responsive - Works on desktop, tablet, and mobile
Mobile Menu - Hamburger menu for small screens
Smooth Scrolling - Navigation links scroll smoothly
4 Main Sections - Home, About, Projects, Contact
Modern Design - Purple and cyan color theme

💡 Key Features Explained
Page Loader

Shows purple spinner when page loads
Automatically disappears after 0.5 seconds
Maximum wait time: 5 seconds

Mobile Menu

Appears on screens smaller than 768px
Click hamburger icon to open/close
Closes when you click a link

Smooth Scroll

Click any navigation link
Page smoothly scrolls to that section
